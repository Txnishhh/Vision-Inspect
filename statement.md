# Project Statement — VisionInspect

## Problem Statement
Manual visual inspection and object identification can be time-consuming and inconsistent. VisionInspect provides an automated image-analysis pipeline that applies Computer Vision techniques to process images and Machine Learning to identify common real-world objects.

## Scope
The system supports two modes: classical OpenCV shape analysis for geometric objects and YOLO-based ML object detection for everyday photographs.

## Target Users
Students, developers, educators, and users demonstrating computer-vision and machine-learning workflows.

## High-Level Features
- Image validation
- OpenCV preprocessing and contour analysis
- Geometric feature extraction
- Shape classification
- YOLO object detection
- Confidence scores and bounding boxes
- JSON and annotated-image reports
